# 0818practice

練習專案集錦，包含多個獨立的 Web 實用工具與視覺化介面。

## 專案內容

1. **台股合併現金流量表財務分析 Dashboard (`dashboard.html`)**
   - 支援 Excel 財務報表解析（SheetJS）
   - 互動式財務圖表展示（ECharts）
   - 現金流量指標結構分析與趨勢視覺化

2. **本地端個資假名化與脫敏工具 (`local_anonymizer_tool.html`)**
   - 純本地端運算，保障資料隱私安全
   - 支援多種脫敏與雜湊演算法（Salted SHA-256）
   - Excel / CSV 批次處理與匯出

3. **TaskPulse - 跨裝置同步待辦事項 (`taskpulse_sync_todo.html`)**
   - 現代化深色 / 淺色主題設計
   - 任務分類、優先級標籤與進度追蹤
   - 支援跨裝置同步與本地持久化儲存
